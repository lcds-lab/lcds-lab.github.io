This Lastinger Center Research Catalyst project, **Enhancing Longitudinal Program Evaluations: Estimating Design Parameters and Illustrating Advanced Quasi-Experimental Methods Using UF Lastinger Center Data**, supports methods and applied examples for longitudinal education evaluation.

Within the lab, this project provides an applied data setting for longitudinal design planning and quasi-experimental methods. It connects methods development with Lastinger Center program data so that design guidance can reflect realistic education evaluation conditions.

## Project Information

- **Funding source:** University of Florida Lastinger Center for Learning Research Catalyst Award 2025
- **Role:** Principal Investigator
- **Project period:** September 1, 2025-August 31, 2026
- **Award amount:** $93,808

## Project Focus

- Estimate design parameters for longitudinal program evaluations.
- Illustrate advanced quasi-experimental methods using Lastinger Center data.
- Support planning guidance for realistic education program evaluations.
